# Oopski

Розширення для Chrome, яке допомагає зорієнтуватися на незнайомому сайті. Клік по іконці кличе на сторінку маскота Упсика. Кажеш йому мету («записатися до терапевта») — він оглядає сайт, підлітає до потрібного елемента й одним коротким рядком каже твоєю мовою, що з ним робити. Після твоєї дії веде далі. Сам він нічого не клацає й не вводить.

- **Коротко за замовчуванням.** У бульбашці один рядок і кілька кнопок; пояснення («Чому?») і подальші кроки («Що далі?») розгортаються на вимогу. Коли Упсик щось питає, варіанти відповіді — кнопки.
- **«Покажи, що тут є»** — тур ключовими зонами сторінки по одній, наприкінці типові цілі, з яких можна почати.
- **Не підглядає.** На платіжних сторінках, біля полів пароля чи картки і коли ти в таке поле клацаєш, Упсик затуляє очі. Значень полів розширення не читає взагалі.

Це прототип для власного користування: потрібен свій API-ключ Anthropic, запити оплачуються з твого акаунта.

## Запуск

Потрібен Node 20 (`nvm use`).

```bash
npm install
npm run build
```

Далі в Chrome: `chrome://extensions` → увімкнути «Режим розробника» → «Завантажити розпаковане» → обрати папку `dist/`. Клік по іконці розширення кличе Упсика на поточну сторінку. Кнопка «⋯» у його бульбашці відкриває бічну панель, де є налаштування (модель, мова), журнал і діагностика; на службових сторінках браузера іконка відкриває панель одразу.

### API-ключ

Є два способи, обирай один:

- **У `.env`** — скопіюй `.env.example` у `.env`, впиши ключ після `ANTHROPIC_API_KEY=` і перезбери. Ключ не доведеться вводити в браузері. Збірка записує його відкритим текстом у `dist/background.js`, тому папку `dist/` нікому не передавай і не публікуй. `.env` і `dist/` в git не потрапляють.
- **У налаштуваннях розширення** — ключ зберігається у сховищі браузера. Якщо задано обидва, діє введений у налаштуваннях.

Під час розробки: `npm run watch`, після змін — кнопка оновлення на картці розширення.

## Перевірка

```bash
npm run typecheck
npm test
```

`npm test` проганяє сценарії сесії проти зібраного service worker з підставними `chrome` та `fetch`; API не викликається. Сторінки в `test/` — для ручної перевірки знімка й підсвітки (кнопки з однаковими класами, shadow DOM, чужий iframe, поле картки).

## Як влаштовано

| Частина | Що робить |
|---|---|
| `src/content` | Скрипт на сторінці: знімок інтерактивних елементів, маскот із бульбашкою (`companion.ts`, малюнок у `mascot.ts`), відстеження дії. Інжектиться лише коли Упсика покликали. |
| `src/background` | Service worker: стан сесії, виклик моделі, блоклист, журнал. `view.ts` вирішує, що маскот каже й пропонує в кожному стані. |
| `src/sidepanel` | Бічна панель: той самий стан сесії розгорнуто, плюс діагностика. |
| `src/options` | Налаштування та зведення журналу кроків. |

Моделі надсилається адреса сторінки без параметрів, заголовки, до 1500 символів тексту та список кнопок, посилань і полів з їхніми підписами. Введені в поля значення не надсилаються.

## Обмеження

- Банківські й платіжні сайти та сторінки з полями картки заблоковано.
- Вміст чужих вбудованих фреймів (віджети запису, оплати) розширення не бачить.
- Лише десктопний Chrome 120+.
