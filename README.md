# Oopski

Розширення для Chrome, яке допомагає зорієнтуватися на незнайомому сайті. Називаєш мету («записатися до терапевта») — Oopski підсвічує наступний елемент і пояснює твоєю мовою, що з ним робити. Після твоєї дії показує наступний крок. Саме воно нічого не клацає й не вводить.

Є також «Огляд сторінки»: короткий тур ключовими зонами й типові цілі, з яких можна почати.

Це прототип для власного користування: потрібен свій API-ключ Anthropic, запити оплачуються з твого акаунта.

## Запуск

Потрібен Node 20 (`nvm use`).

```bash
npm install
npm run build
```

Далі в Chrome: `chrome://extensions` → увімкнути «Режим розробника» → «Завантажити розпаковане» → обрати папку `dist/`. Клік по іконці розширення відкриває бічну панель; ключ і модель задаються в «Налаштування та журнал».

Під час розробки: `npm run watch`, після змін — кнопка оновлення на картці розширення.

## Перевірка

```bash
npm run typecheck
npm test
```

`npm test` проганяє сценарії сесії проти зібраного service worker з підставними `chrome` та `fetch`; API не викликається. Сторінки в `test/` — для ручної перевірки знімка й підсвітки (кнопки з однаковими класами, shadow DOM, чужий iframe, поле картки).

## Як влаштовано

| Частина | Що робить |
|---|---|
| `src/sidepanel` | Бічна панель: мета, поточний крок, кнопки. Малює стан сесії зі сховища. |
| `src/background` | Service worker: стан сесії, виклик моделі, блоклист, журнал. |
| `src/content` | Скрипт на сторінці: знімок інтерактивних елементів, підсвітка, відстеження дії. Інжектиться лише на час активної сесії. |
| `src/options` | Налаштування та зведення журналу кроків. |

Моделі надсилається адреса сторінки без параметрів, заголовки, до 1500 символів тексту та список кнопок, посилань і полів з їхніми підписами. Введені в поля значення не надсилаються.

## Обмеження

- Банківські й платіжні сайти та сторінки з полями картки заблоковано.
- Вміст чужих вбудованих фреймів (віджети запису, оплати) розширення не бачить.
- Лише десктопний Chrome 120+.
